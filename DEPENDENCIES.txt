# Cloud Cost Optimizer — Dependency Map

This document maps every Python package used in the project to the specific files that import it.

---

## Core Frameworks & UI

### `streamlit`
| File | Usage |
|------|-------|
| `app/dashboard.py` | Main UI framework — tabs, columns, metrics, charts, chat, uploader |
| `app/auth.py` | Login page, registration, logout button UI |
| `app/admin.py` | Admin dashboard UI for users/teams/orgs management |
| `app/profile.py` | User profile page |
| `theme/light.py` | Theme toggle UI component |
| `run.py` | Launches Streamlit server via subprocess |

---

## Web Server & API

### `fastapi`
| File | Usage |
|------|-------|
| `backend/main.py` | FastAPI app creation, CORS middleware, router registration |
| `backend/dependencies.py` | FastAPI security (HTTPBearer), dependency injection |

### `uvicorn`
| File | Usage |
|------|-------|
| `run.py` | Launches FastAPI server with `uvicorn` command |
| (CLI) | `uvicorn backend.main:app --port=8000` |

### `python-multipart`
| File | Usage |
|------|-------|
| `backend/api/costs.py` | Parses uploaded file data via `UploadFile` / `File()` |

### `PyJWT` (`jwt`)
| File | Usage |
|------|-------|
| `backend/dependencies.py` | Creates and decodes JWT tokens for authentication |

### `httpx` / `requests`
| File | Usage |
|------|-------|
| (future use) | For Streamlit to make HTTP calls to FastAPI backend |

## Data Manipulation

### `pandas`
| File | Usage |
|------|-------|
| `app/data_generator.py` | Creates DataFrames for synthetic cost/resource/recommendation data |
| `app/data_loader.py` | Reads CSV/Excel/JSON/Parquet, column mapping, validation, normalization |
| `app/cost_analyzer.py` | Cost aggregation, grouping, wastage analysis, forecasting prep |
| `app/dashboard.py` | DataFrame filtering, grouping, metric calculations |
| `app/profile.py` | User activity data display |
| `app/visualizations.py` | DataFrame manipulation for chart data |
| `app/admin.py` | User/team/org data queries |
| `app/auth.py` | User data lookups |
| `ml/forecaster.py` | Time-series data preparation for Prophet/XGBoost |
| `ml/anomaly.py` | DataFrame operations for anomaly detection |
| `ml/clustering.py` | DataFrame operations for KMeans/DBSCAN |
| `database/seed.py` | Seed data creation |
| `AI/integration.py` | Wraps data for AI chatbot context |
| `backend/api/costs.py` | API responses from DataFrames |
| `backend/api/analytics.py` | API responses from analysis results |

### `numpy`
| File | Usage |
|------|-------|
| `app/data_generator.py` | Random number generation, seasonal/trend factors |
| `app/cost_analyzer.py` | Numerical computations for percentiles, thresholds |
| `app/dashboard.py` | (imported, used implicitly) |
| `app/visualizations.py` | Numerical array operations for charts |
| `ml/forecaster.py` | Array operations for forecasting |
| `ml/anomaly.py` | Array operations for anomaly detection |
| `ml/clustering.py` | Array operations for clustering |
| `AI/embeddings.py` | Embedding vector operations |
| `AI/vector_store.py` | Vector similarity computations |
| `backend/api/analytics.py` | Data conversion for API responses |
